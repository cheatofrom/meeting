# 演示图片说明

此目录用于存放项目演示截图和GIF动图。

## 需要的图片文件

### 1. 桌面端截图 (desktop-demo.png)
- **建议尺寸**: 1920x1080 或 1440x900
- **内容要求**: 
  - 显示完整的桌面端界面
  - 包含语音识别功能正在工作的状态
  - 展示识别结果文本
  - 显示连接状态和配置选项

### 2. 移动端截图 (mobile-demo.png)
- **建议尺寸**: 375x812 (iPhone) 或 360x640 (Android)
- **内容要求**:
  - 展示移动端响应式界面
  - 显示触屏友好的操作按钮
  - 展示移动端特有的交互元素
  - 体现移动端的适配效果

### 3. 功能演示GIF (demo.gif)
- **建议时长**: 10-30秒
- **建议尺寸**: 800x600 或更大
- **内容要求**:
  - 展示从开始录音到显示识别结果的完整流程
  - 包含实时语音识别的动态效果
  - 展示关键功能的操作过程
  - 文件大小控制在5MB以内

## 截图建议

### 桌面端截图要点
1. 确保界面清晰，字体可读
2. 展示核心功能区域
3. 包含一些示例识别文本
4. 显示连接状态为"已连接"
5. 可以包含一些配置参数展示

### 移动端截图要点
1. 使用真实的移动设备或模拟器
2. 展示响应式布局的效果
3. 突出移动端的交互特性
4. 确保按钮和文字在移动端的可用性
5. 可以展示横屏和竖屏两种模式

### GIF制作建议
1. 使用屏幕录制工具 (如 OBS, QuickTime, 或在线工具)
2. 录制关键操作流程
3. 适当加速以缩短时长
4. 确保画质清晰但文件大小合理
5. 可以添加简单的文字说明

## 文件命名规范
- `desktop-demo.png` - 桌面端主界面截图
- `mobile-demo.png` - 移动端主界面截图  
- `demo.gif` - 功能演示动图
- 可以添加更多截图，如 `desktop-settings.png`, `mobile-recording.png` 等

## 注意事项
- 所有图片应该是项目的真实截图，不要使用模拟或设计稿
- 确保截图中没有敏感信息 (如真实的IP地址、个人信息等)
- 图片格式建议使用 PNG (截图) 和 GIF (动图)
- 保持图片质量的同时控制文件大小
